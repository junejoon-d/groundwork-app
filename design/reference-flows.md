# Reference flows to study before building each screen

Copy the **structure** of a flow (steps, order, what's asked when), never the look. Everything visual comes from Harbor (`src/theme/tokens.ts`).

The project's Mobbin connector works (paid plan since 2026-10-20). When you start a flow, open its links below, or ask Claude to pull the screens through the Mobbin connector. Use the screens as the `design-check` reference once the screen is built. Mobbin image links expire after 30 days, so don't commit them. Link to the `mobbin.com/flows/...` or `mobbin.com/screens/...` pages instead.

| Groundwork flow | Mobbin references | Structure worth copying |
|---|---|---|
| Sign up and onboarding | [Strava – Onboarding (email first)](https://mobbin.com/flows/4f843ca4-a7d4-4ace-a924-613b749fcefe), [Strava – Onboarding (password)](https://mobbin.com/flows/e3d57f26-77ec-46c5-a836-da7c8288f669), [Runna – Onboarding](https://mobbin.com/flows/1689d6d5-e245-4369-9dae-320bd863136b) | Strava creates the account first (Apple, Google or email), then asks one question per screen. The birthday screen says why it's asked, including "to keep younger users safe", and that the birthday is never shown. Runna asks for the level as 3 descriptive cards, with a "?" sheet explaining why, and Continue stays disabled until one is picked. |
| Permission explainers | [Runna – Onboarding (notification pre-prompt)](https://mobbin.com/flows/1689d6d5-e245-4369-9dae-320bd863136b), [Strava – privacy explainer](https://mobbin.com/screens/f812a6c1-1550-4000-9b03-c5b1034443de), [Polarsteps – Location services information](https://mobbin.com/flows/a5eeb480-1524-4a31-b819-5cc74f7fbef2) | Runna shows a full-screen benefit pre-prompt with one Continue button before the iOS dialog. Polarsteps covers the denied case with an illustrated "Location → Always" sheet and an "Open phone settings" button. Mobbin has no Hinge notification or Strava location pre-prompt. |
| Profile and sports setup | [Tonal – Preferences](https://mobbin.com/flows/fe619289-85e4-443d-876f-49488eaf5c30), [Strava – Editing profile](https://mobbin.com/flows/04522233-5dee-40d8-8dc8-3f90a41b6ae1), [Strava – Profile detail](https://mobbin.com/flows/fb26ef13-1a8e-4ae7-aa1e-7f39b2b24698) | Tonal uses a few summary rows (goals, level, days per week, duration). Each row shows its current value and opens its own picker, so there's no long form. Strava has a single primary-sport row and a "Your profile is 80% complete" card, so setup can be finished later. |
| Browse nearby partners or activities | [Meetup – Explore](https://mobbin.com/flows/cfb4b412-0d61-45d0-b815-69f6faf0c003), [Meetup – Searching events](https://mobbin.com/flows/5bc224d9-993a-4998-a846-c44b0ff9b443), [ClassPass – Searching mapped area](https://mobbin.com/flows/bd0c8adc-c992-4746-8903-0fe457bb34c2) | Meetup has time chips (Today, Tomorrow, Weekend), a filter button with a count badge, cards showing distance and "N going", a floating Map button, and a friendly empty state that suggests what to change. ClassPass puts the map above a list sheet, and its filter row opens bottom sheets with Clear and Save. |
| Match request and accept | [Hinge – Likes you](https://mobbin.com/flows/1ea5dfb6-a5ff-4a8f-9856-5b6f601f7b9b), [Hinge – Matching with a user](https://mobbin.com/flows/8e0105fd-d7f7-427a-acf2-b6ebf61c9cdc), [Bumble – Matching with a user](https://mobbin.com/flows/9fdb4acf-d06f-43fc-b3ff-979145c67725), [Stardust – Accept follow request](https://mobbin.com/screens/115393bb-e979-49e0-a832-66397c1eb64b) | Hinge keeps incoming requests in their own list. Opening one gives accept, with an optional first message, or decline. Bumble's match screen puts a message box right on it. Stardust is the simplest pattern: a main accept button with a text-link decline below it. None of these show a "sent, waiting" state for outgoing requests, so design that one ourselves. |
| Session details and scheduling | [Meetup – Event detail](https://mobbin.com/flows/bda54918-bc53-4eb7-ba68-760751f893b8), [Meetup – Registering for an event](https://mobbin.com/flows/285d4cee-cb36-4dca-b78c-881c70da7dd7), [Partiful – Event detail](https://mobbin.com/flows/eec6cdc4-0b7c-4d8c-92c7-825a2121599d) | Meetup puts title, time (with add to calendar), place and organizer above the fold, with a sticky "Attend" bar. After you join, the bar changes to "You're going · Edit". Attendees, the map and "Report this event" sit lower down. Partiful has one action bar: Going, Maybe or Can't go. |
| Chat | [Strava – Messages intro](https://mobbin.com/flows/06c4656e-4d37-4659-8a64-83298a698177), [Strava – Messages](https://mobbin.com/flows/5a56290a-ace2-4fe8-a654-15be5c175f5a), [Hinge – Unmatching a user](https://mobbin.com/flows/c1718131-63ac-4e20-b3e3-60ea05a73953), [Bumble – Sending a chat](https://mobbin.com/flows/6a312979-9402-40e8-b964-f0b771105c4e) | Strava introduces messaging by asking who may message you. Hinge groups conversations into "Your turn" and "Their turn", and unmatching asks "Are you sure?" first. Bumble's chat menu holds Unmatch and Report, with Report in red. None of these show first-message prompts. |
| Safety: report and block | [Hinge – Reporting a user](https://mobbin.com/flows/d5d53317-bbcc-4826-a689-67a7121869a5), [Bumble – Reporting a user](https://mobbin.com/flows/7d560bc0-3903-4a5a-8ae4-88a7475a8fc6), [Bumble – Reporting a user (alt)](https://mobbin.com/flows/b4044ab8-54b2-4107-924a-7163d86dcc49) | Reporting takes 2 to 3 taps: profile menu, Report, then a one-tap reason. Hinge's reasons include "Underage or minor" and "Someone is in danger". Bumble says up front that the other person won't know, blocks them as part of the report, then confirms "You've blocked and reported X" and says where updates will appear. |
| Identity and age verification | [Bumble – Verifying a photo](https://mobbin.com/flows/6c74489d-ebb8-423d-9964-004637611b19), [Bumble – Verifying my profile](https://mobbin.com/flows/eb66bdc5-a349-405a-8c36-a8a9a8158261), [Tinder – Verifying profile](https://mobbin.com/flows/717657be-043c-45a5-be1d-9702d1ea4596) | Both show an explainer before the camera opens. Tinder's order: why it's needed and that the profile stays hidden until it's done, then "Complete now" or "Maybe later", the capture, "Uploading encrypted scan", and finally "Under review (a few minutes)". |
| Connect Apple Health | [Strava – Connecting with Health](https://mobbin.com/flows/c6d7f7a3-a6a8-419f-a8db-a7c8858cbc3c), [Strava – Connecting with Health (alt)](https://mobbin.com/flows/2075d21d-9f58-4551-ac3b-29d2e87496ba), [Runna – Connecting to Apple Watch](https://mobbin.com/flows/fc01ea0c-344b-4ec0-b2c1-767d4d7ca5c6) | Strava shows one explainer screen saying what syncs and why, then the HealthKit sheet. Afterwards the row shows a check and opens separate import and send toggles. Runna lists each permission on its own card, with "when prompted, select X" and the reason. |

Not on Mobbin: Playtomic, and Bumble For Friends (only the Bumble dating app is there). The Nike Run Club search returned its plan-start flow, not onboarding.
